# Contributing

## Issues

Feel free to
[file an issue](https://docs.github.com/en/issues)
if you notice bugs or you think reworks are needed.

## Contributions

To contribute features or bugfixesplease submit a
[pull request](hhttps://docs.github.com/en/pull-requests)
.

## Guidelines

Simple guidelines for pull requests:

* The repository is based on shell scripts,
so use best practices and sane guidelines when changes are made.
* Lint and follow coding standards.
* Perform local testing on relevant environments before submitting.
